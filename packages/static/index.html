咨询定量工具箱

DFSS / CDOC 方法改造 · 需求分析 → 方案设计

给咨询判断装上可复核的刻度。六个工具把"我觉得 A 更好"变成一张别人能复核的加权矩阵 / 概率分布。

源自 Cummins DFSS(CDOC 路线图)。只保留"把定性判断结构化为半定量评分"的方法——咨询现场缺测量数据,SPC/能力研究/DOE 实验这类数据密集型工具未纳入。全部单文件、本地运行、数据存在浏览器、可导出 JSON。

K

Kano 模型

KANO MODEL · BETTER-WORSE
把客户需求分成基本 / 期望 / 魅力三类,算 Better-Worse 满意度系数,四象限散点定位。
定量产出:Better / Worse 系数 + 四象限分类 → 哪些必须做、哪些能制造惊喜
需求分析打开 →
C

C&E 因果矩阵

CAUSE & EFFECT MATRIX
输出带重要度权重,过程因素逐项打关系分(1/3/9),算出每个因素的总影响分。
定量产出:关键因素得分排序 → 锁定该优先管控的"关键少数 X"
需求分析打开 →
Q

QFD 质量屋

QUALITY FUNCTION DEPLOYMENT
客户诉求权重 × 关系矩阵,把需求定量传递到方案模块;含竞争对标规划矩阵。
定量产出:方案模块优先级得分 → 该优先投入哪个模块(链路枢纽)
需求 → 方案打开 →
P

Pugh 方案比选

PUGH CONCEPT SELECTION
多方案对一个基准逐准则打分(＋＋/＋/0/−/−−),加权得分排序,可迭代收敛。
定量产出:加权得分 + 正负计数 → 把"我觉得 A 好"拉回可复核的账
方案设计打开 →
F

FMEA / RPN

FAILURE MODE & EFFECTS
失效模式按严重度 × 发生度 × 探测度算 RPN,分级配色,展示缓解前后对比。
定量产出:RPN 风险排序 + 降幅 → 风险从"高中低"升级为可排序的优先级
风险评估打开 →
M

蒙特卡洛 ROI

MONTE CARLO SIMULATION
每个不确定输入定义成分布,跑万次抽样,看输出的概率形状 + 敏感性 Tornado。
定量产出:达标概率 + P10–P90 区间 → 把"大概能回本"变成"X% 概率达标"
ROI 测算打开 →
用法提示:六个工具可单用,也可按上面的链路接力。每个都自带"数字化转型"示例数据,打开即可看懂逻辑;改成自己的客户场景后,数据自动存在浏览器本地(刷新不丢),也可导出 JSON 存档。
不是替代判断,是给判断装刻度——最终客户拿到的不是"我们建议做 A",而是"A 在加权矩阵得 8.3、风险 RPN 已降到 60 以下、ROI 在 80% 置信下落在 1.4–2.1x"。
